# Pharmacy Service

Microservice 4 du projet SmartCare, responsable de la gestion des médicaments et du stock de la pharmacie hospitalière.

## Objectif
Développer un service indépendant permettant de gérer les médicaments disponibles, les quantités en stock et les mouvements de stock.

## Fonctionnalités
- [ ] Ajouter un médicament
- [ ] Afficher la liste des médicaments
- [ ] Rechercher un médicament
- [ ] Modifier les informations d'un médicament
- [ ] Supprimer un médicament
- [ ] Gérer les quantités en stock
- [ ] Signaler les médicaments en rupture de stock
- [ ] Gérer les dates d'expiration des médicaments
- [ ] Créer une ordonnance médicale
- [ ] Associer une ordonnance à un patient et à un médecin
- [ ] Consulter les ordonnances
- [ ] Créer les API REST
- [ ] Configurer la base de données
- [ ] Tester les endpoints

## Communication avec les autres microservices
- E-Prescription Service : consulter les prescriptions validées afin de préparer la délivrance des médicaments
- Smart Service : fournir des statistiques sur les stocks et les médicaments
