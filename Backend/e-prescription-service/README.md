## E-Prescription Service

Microservice 3 du projet SmartCare, responsable de la gestion des prescriptions médicales électroniques et des demandes de renouvellement d'ordonnances.

# Objectif
Développer le microservice E-Prescription Service pour Smart Hospital, permettant de gérer les prescriptions médicales électroniques, les médicaments prescrits et les demandes de renouvellement d'ordonnances.

# Fonctionnalités
- [ ] Créer une prescription électronique pour un patient
- [ ] Afficher la liste des prescriptions
- [ ] Rechercher une prescription par patient ou identifiant
- [ ] Consulter les détails d'une prescription
- [ ] Modifier une prescription lorsque son statut le permet
- [ ] Annuler une prescription
- [ ] Associer une prescription à un patient et à un médecin
- [ ] Ajouter des médicaments à une prescription
- [ ] Définir la posologie, la fréquence et la durée du traitement
- [ ] Gérer les statuts des prescriptions (active, expirée, annulée)
- [ ] Créer une demande de renouvellement d'ordonnance
- [ ] Consulter les demandes de renouvellement
- [ ] Approuver ou refuser une demande de renouvellement par un médecin autorisé
- [ ] Consulter l'historique des prescriptions d'un patient
- [ ] Contrôler les accès aux prescriptions et tracer les modifications
- [ ] Créer les API REST
- [ ] Configurer la base de données
- [ ] Tester les endpoints
