# SmartCare

## Objectif
Développer l'interface web de la plateforme SmartCare pour permettre aux utilisateurs d'accéder aux différentes fonctionnalités du système hospitalier.

## Fonctionnalités
- Tableau de bord principal
- Interface de gestion des patients
- Interface de gestion des rendez-vous
- Interface de gestion des prescriptions électroniques
- Interface de gestion des médicaments et des stocks
- Affichage des statistiques hospitalières
- Authentification et gestion des accès

## Communication avec le Backend
Le Frontend communiquera avec les microservices à travers des API REST, idéalement via une API Gateway.
